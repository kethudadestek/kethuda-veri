# Kethüda · resmi rakamlar

Bu depo Kethüda uygulamasının kullandığı güncel resmi rakamları tutar:
kira artış sınırları (TÜFE 12 aylık ortalaması), gelir vergisi dilimleri, asgari ücret,
kıdem tavanı, bedelli askerlik ücreti ve emekli zammı.

- Kira oranları her ay otomatik eklenir (TCMB EVDS'den, `guncelle.mjs`).
- Diğer rakamlar yılda bir-iki kez değişir; değiştiğinde `parametreler.json` elle güncellenir.
- Elle girilen değerlerin üzerine otomatik güncelleme yazmaz.

Kaynaklar: TÜİK, TCMB EVDS, Resmî Gazete, SGK, MSB.
